title: Comment trouver des offres ?
---

Deux chemins complémentaires.

**Le fil « Recommandé pour vous »** classe les offres selon votre note de compatibilité, puis
selon vos préférences — type de contrat, lieu, mobilité internationale.

**La recherche** vous laisse filtrer vous-même : métier, lieu, type de contrat, niveau.

Les offres notées apparaissent toujours avant les offres sans note, mais aucune offre n'est
jamais retirée de la liste : une note manquante ne vous prive pas d'une opportunité.

title: Pourquoi cette offre m'est-elle proposée ?
---

Le classement combine trois éléments :

- votre **note de compatibilité** sur l'offre, qui pèse le plus ;
- vos **préférences respectées** — contrat, lieu, mobilité ;
- la **proximité entre le rôle que vous recherchez et le métier de l'offre**.

Une préférence non renseignée ne vous pénalise pas : elle n'entre simplement pas dans le
calcul. C'est pourquoi remplir la section « rôle recherché » améliore nettement la
pertinence de ce qui vous est proposé.

Le classement ne filtre pas : une offre qui ne coche que trois critères sur quatre vous est
quand même montrée.
