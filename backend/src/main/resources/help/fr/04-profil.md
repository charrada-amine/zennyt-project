title: Que voit un recruteur de mon profil ?
---

Un recruteur voit votre nom, votre photo, votre localisation, votre Fit Score sur son offre,
et le résumé de vos compétences généré à partir de vos jeux et de vos tests.

Il ne voit pas le détail épreuve par épreuve de vos parties, ni vos Fit Score sur les offres
des autres recruteurs.

Le résumé qui lui est présenté est rédigé différemment de celui que vous voyez : le vôtre est
formulé pour vous être utile, le sien pour appuyer une décision de recrutement.

title: Mon CV influence-t-il mon Fit Score ?
---

Non. Le Fit Score ne repose que sur les mini-jeux et les tests techniques.

Votre CV sert ailleurs : il alimente le résumé de vos compétences présenté au recruteur, et
il reste consultable par lui. Mais il n'ajoute ni ne retire aucun point à votre note.

category: Profil
title: Pourquoi compléter mon profil ?
---

Un profil complet vous rend visible dans les recherches des recruteurs et améliore la
pertinence des offres qui vous sont proposées.

Les éléments qui comptent le plus :

- le **rôle recherché**, qui sert à rapprocher votre profil des métiers des offres ;
- vos **préférences** — type de contrat, lieu de travail, mobilité — qui font remonter les
  offres correspondantes ;
- votre **CV**, qui nourrit le résumé présenté au recruteur.

Sans texte décrivant le rôle recherché, le rapprochement automatique avec les métiers ne peut
pas fonctionner : les offres vous seront proposées, mais moins bien classées.
---
slug: profil-portfolio
audience: CANDIDATE
category: Profil
title: À quoi sert le lien vers mon portfolio ?
---

Pour les métiers créatifs, le portfolio est le mode d'évaluation principal — parfois le seul.
Un photographe ou un illustrateur ne se juge pas sur un QCM.

Le portfolio n'est pas noté automatiquement : c'est le recruteur qui le consulte. Sur les
métiers concernés, la plateforme le lui signale explicitement plutôt que d'afficher une note
technique qui n'aurait pas de sens.

Renseignez ce lien si votre métier relève de la création : sans lui, le recruteur n'a rien à
regarder.
