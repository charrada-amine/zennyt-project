title: Comment fonctionnent les tests techniques ?
---

Un test technique est un QCM attaché à une offre par le recruteur. Il mesure la partie
« hard skills » de votre Fit Score.

La note de passage est de **70 %**. Elle est la même pour toutes les offres : un recruteur ne
peut pas l'abaisser pour sa propre offre.

Toutes les offres n'ont pas de test. Quand il n'y en a pas, votre Fit Score repose
entièrement sur les mini-jeux.
---
slug: tests-note-technique
audience: BOTH
category: Tests techniques
title: Comment la note technique est-elle calculée ?
---

Elle n'est pas la note d'un seul test. C'est une estimation de votre niveau **sur le métier**,
construite à partir de tous les QCM que vous avez passés pour ce métier — y compris chez
d'autres recruteurs.

Les résultats sont combinés en donnant plus de poids aux plus récents : le dernier compte
pour moitié au moins, le précédent pour moitié moins, et ainsi de suite. Votre niveau
d'aujourd'hui pèse donc toujours plus que celui d'il y a un an, sans que l'historique
disparaisse.

Conséquence utile : un recruteur qui n'a attaché aucun test à son offre peut quand même voir
une évaluation technique, si vous avez été testé ailleurs sur le même métier.

Deux précisions :

- « même métier » signifie **le même poste du référentiel**, pas le même secteur ni la même
  famille de métiers ;
- le test passé pour l'offre que vous consultez garde toujours le premier rang, même s'il
  est plus ancien.

title: J'ai abandonné un test, est-il compté ?
---

Non. Une tentative abandonnée n'est pas un résultat et n'entre pas dans votre note.

En revanche, un test dont le **temps est écoulé** est noté normalement, sur la base des
réponses données.
---
slug: tests-repasser
audience: CANDIDATE
category: Tests techniques
title: Puis-je repasser un test technique ?
---

Oui, mais gardez en tête que les résultats se cumulent : un nouveau test s'ajoute à
l'historique, il ne l'efface pas.

Concrètement, pour faire monter votre estimation, il faut faire mieux que votre propre
moyenne. Multiplier les tentatives sans progresser ne sert donc à rien — c'est voulu : sinon
il suffirait de repasser un test dix fois pour n'en garder que le meilleur résultat.
